# Rainsoft GastKompass – Nachfrage-Test (Entwurf, 09.10.2026)

Status: Nur fuer interne Vorbereitung. Keine Nachrichten versendet, keine Kunden oder Verkaufserloese behaupten.

## Zielgruppe
Privatzimmer, Pensionen und Ferienwohnungen mit 1-10 Einheiten im DACH-Raum. Fokus auf Betriebe ohne existierende digitale Gaestemappe.

## Qualifizierungsfragen (max. 5 Minuten)
1. Wie oft beantworten Sie gaengige Gaestefragen zu WLAN, Anreise, Parken und Ausfluegen?
2. Wie stellen Sie diese Informationen momentan bereit?
3. Welche Gaestefragen kosten am meisten Zeit?
4. Waere eine bearbeitbare, per QR-Code abrufbare Gaestemappe eine Erleichterung?
5. Wuerden Sie dafuer nach einem kostenlosen Test 19 EUR pro Monat bezahlen? (Ja / Nein / vielleicht; Grund)
6. Welche einzige Funktion fehlt, damit Sie die Software tatsaechlich nutzen?

## Kontaktdokumentation (keine personenbezogenen Daten ins oeffentliche Repo!)
Nur aggregierte Kennzahlen dokumentieren. Individuelle Kontaktdaten ausschliesslich in datenschutzkonformem, zugriffsgeschuetztem CRM mit Rechtsgrundlage speichern. Keine Massenwerbung ohne vorherige Pruefung oesterreichischer Vorschriften (insbesondere §107 TKG).

- Kundentrennung auf Server und in Datenbank; Authentifizierung; Datenportabilitaet.
